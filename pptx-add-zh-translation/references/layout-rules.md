# 各类页面的排版做法

以下做法在 CST308 第 1 章样稿（第 4、9、38、73 页）里渲染验证过。数值是起点，最终以渲染 PNG 为准。

## 判断空间的顺序

1. 用留白：中文放在对应英文**正下方**（段落）或**右侧同一行**（标题、短标签）。
2. 小幅移动：标题上移 ≤15pt、图片/公式平移让位；不改变元素之间的阅读顺序。
3. 缩英文：`font_scale` 0.8–0.9。**累计不低于 0.75**（同一个框的多次 `font_scale`/`table_scale` 相乘），低于就是 `apply_plan.py` 的 ERROR。缩之前先看能不能少加几行：代码/汇编行不加中文行，短标签用 `inline`。
4. 缩中文：到下限 12pt 为止。
5. 还放不下 → 报告给用户，列出该页和原因。

## 标题

- 中文用独立 `textbox`，24pt，放在英文标题文字结束处右侧约 10pt、同一垂直中线（标题文字宽度从 PNG 量）。
- 右侧不够（英文标题很长）→ 放在标题下方 20–24pt；如果和下面正文冲突，标题 `adjust dy` 上移。
- 不要把中文插进标题占位符本身（底部对齐会把英文顶上去，等宽标题字体也不适合中文）。

## 项目符号正文

- `para_after`，中文 = 英文 × 0.75（24pt→18pt；正文已缩到 19pt 时中文约 14pt）。
- 正文较满时先 `adjust font_scale 0.8`，再插中文。
- 中文段落与英文段落之间不加段前距（`space_before_pt` 默认 0），英文要点之间原有间距保留，这样一眼能看出"一英一中"一组。
- inventory 的字号是**实际渲染字号**。标了 `AUTOFIT 85%` 的框，原稿开过"溢出时缩小文字"，列出的字号已经乘过 85%；`apply_plan.py` 会把它换算成真实字号写进去，并关掉这个框的自动缩小（否则缩放会叠加，加了中文、文字溢出后，WPS/PowerPoint 一编辑还会再缩一轮）。所以加中文后文字溢出不会被自动缩小，渲染检查会报出界/重叠，要用 `dh` 加高框或少加行来解决。

## 标签 + 代码/汇编示例的行（如 `1-address  add A  acc ← acc + mem[A]`）

- 指令、寄存器传送式属于代码，**不要**整行复写成中文行（会让行数翻倍，迫使英文缩到 0.6，CST308 Ch2 p16 踩过）。
- 只翻标签：`inline` 加在行尾（`（1 地址）`，`sep` 用 4 个空格）；纯代码行（只有 `load R1, A  R1 ← mem[A]`）用 `skip`（why: 代码）。
- 分类标题（`Stack (1960s to 1970s…)`）照常 `para_after`，`space_before_pt: 3`（原框行距被压到 90% 时，不加会报 `glyphs_touch`）。

## 单行说明 / 带底色的标签

- `inline`：中文接在英文后面。先 `font_scale 0.75` 给中文腾出宽度，确认不换行（换行会把底色框撑高）。

## 表格

- `cells`，每格英文下面一行中文；表头中文继承红色粗体。
- 典型参数：`table_box` 加宽到页面可用宽度（如 x=40, w=880），`table_scale 0.7`（20pt→14pt），中文 12pt（`scale 0.86`）。
- 宽列让大部分单元格英文、中文各一行，表格高度反而比原来小。

## 图片中的英文（截图、SmartArt 转成的图、示意图）

- 只标重要标注：图中方框/箭头/部件名称。在英文标注正下方或右侧加 13–14pt 的 `textbox`，`align: ctr` 对齐方框中心。
- 坐标从 PNG 量：`pt = 像素 × 72 / dpi`（render_check 默认 dpi=110）。
- 检查器会对"中文压在图片上"报 warn：标注本来就该在图里时属于正常，看 PNG 确认没有挡住图中内容即可。

## 公式（OLE / 图片公式）

- 公式本身不改。下面加一行 13pt 的 `textbox` 释义：`CPU 时间 = 程序的 CPU 时钟周期数 × 时钟周期时长`（符号和运算符照抄，变量名翻成中文）。
- 正文插入中文后要点会下移，公式要用 `adjust dy` 跟着下移，与对应要点垂直对齐（从渲染 PNG 量偏差）。

## 代码、命令、程序输出

- 不翻译、不移动、不缩放（缩放会破坏对齐）。中文只给代码块前后的说明文字。
- 汇编行尾的注释（`; Register R1 ← A-B`）、C 注释也不译：它们是代码的一部分。
- "Expected output / Sample input" 这类程序输入输出样例整块保留：里面的 `KEYWORD`、`MALFORMED_FLOAT` 是程序要原样打印的字符串，译成中文就错了。

## 已有中文的页面

- 已有中文文字不改。若它压住标题或别的元素（如第 4 页），挪对方或挪它，二选一，挪动量尽量小。
- 已有整段译文只覆盖部分英文时，缺的条目照常补。

## 放弃自动处理、交给用户的情况

- 按段落播放动画的文本框需要逐条中文（只能用独立文本框，动画不同步）。
- 文字极满、缩到下限仍放不下。
- 视频画面、照片里的大段英文。
